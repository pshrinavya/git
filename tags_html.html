The strong tag marks text with strong importance, usually shown bold.

The em tag marks text with stress emphasis,usually shown in ilalics.

The mark tag highlights text for reference, like key term.

Water is written as H2O, using the sub tag for subscript.

Einstein's equation is E=mc2, using the sup tag for superscript.

The code tag is used for short pieces of computer code, such as let x=10;
